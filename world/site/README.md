# Comfy Days · World, Europe & USA

One public site, one climate source, one calculation engine.

Static HTML/CSS/JavaScript interface with same-origin Cloudflare Worker routes for climate and monthly history; visitor-direct public API queries for air quality. The published runtime is backed up from current Sites source; see [query service](../query-service/README.md). Build from the repository root with `npm ci && npm run build`.

Current live defaults: daily minimum **≥14°C**, daily maximum **≤30°C**, rain **≤4 mm/day**, sunshine **off** (6h when enabled), AQI **off**. These temperature controls predate the AQI filter. Highlights: score **≥7** and days/year **≥120**. Temperature loss uses the larger high/low deviation, not their sum. [Full rules, examples, annualization and implementation notes](docs/COMFORT-RULES.md).

2020–2025 contains 2,192 daily records. A point must have valid paired temperature and precipitation on at least 90% of the days in every month (all 72 months for the six-year view). Score sums divide by the number of available paired records. Comfortable days are estimated as qualifying records / available paired records × calendar days / years: 2,192/6 for the six-year view, or 365/366 for a selected year. With complete records this equals actual counts / years. Missing observations are never imputed or interpreted as dry. Coverage is displayed for each inspected point.

Sources: Copernicus ERA5 / ECMWF, distributed by Open-Meteo AWS Open Data. The native supplied grid is 0.25°; the existing map samples exact grid centres every 0.5°, without spatial interpolation or elevation downscaling. Temperature is the maximum of 24 hourly 2 m values; precipitation is their total (including snow water equivalent) from 00:00–24:00 UTC. Original stored hourly temperature precision is 0.05°C; no API display rounding is applied. Missing hourly values propagate to daily missing values. Both variables and all region tabs use ERA5 only. No CPC/E-OBS fallback or Best Match model mixing. Coastal cells may differ substantially from nearby land stations; the Miami audit is in `docs/MIAMI-SOURCE-VALIDATION.md`.

`assets/metadata.json` describes coordinates, periods, the original archive baseline, palette, and climate chunks. Current UI defaults are in `uiDefaults()` in app.js; `assets/defaults-v2.json` describes current compact presets. `assets/audit.json` records checks against original daily arrays. Climate chunks contain temperature counts and fractional sums, and joint temperature/rain counts, Float64 temperature sums and exact integer temperature endpoint counts. Format version 4 uses lossless byte-shuffled Float64 joint sums and omits data for ineligible cells. It supports exact per-day clipping at zero for integer temperature bounds and half-point rain penalties. This supports exact recalculation for the supported controls without shipping all raw daily records. `climate-core.js` parses and calculates; `climate-worker.js` fetches and recalculates off the UI thread. Default Float32 maps differ from Float64 calculations only by storage precision; readouts are rounded to one decimal.

Colors use fixed bounds 0–10 score and 0–150+ days, preserving the original palette. These color limits do not cap numeric results. Nearby sampled points extend to the coastline for display, at most 0.75°; numeric readouts identify the sampled point. Areas below monthly coverage requirements remain gray; the eligibility rule also applies to Antarctica.

PNG exports include selected period, metric, temperature range, day-count rain limit, all rain penalty bands, source, annualization, and social handles.

Place names: GeoNames cities1000, admin1CodesASCII, countryInfo, CC BY 4.0 (https://www.geonames.org/). Nearest city is computed with spherical great-circle distance from the click, among the listed settlements (population >1,000 or selected administrative seats). Its state/region is the city’s region, not a claim that the clicked point belongs to that city/state. Place names appear even where climate data are missing. Decoded climate memory is bounded to four chunks; calculation streams through the dataset.

Public interface: World, Europe and USA are geographic viewport presets over the SAME arrays, climate grid and rule controls. Switching region does not refetch, recalculate or alter the selected climate cell. USA opens the contiguous states with Alaska/Hawaii shortcuts. The same details panel shows nearest listed city, its state/region/country, click distance, both metrics, selected period, paired-record coverage and climate cell coordinates in all tabs. Comfort score is the default and primary metric; comfortable days/year remains available as the secondary metric.

Navigation: locally bundled MapLibre GL JS 6.14.0 (BSD-3-Clause) with geographic drag, inertial pan, cursor-anchored wheel zoom, keyboard and touch pinch. OpenFreeMap / OpenStreetMap vector tiles supply sharp city and state names, boundaries and roads as users zoom. English place labels are preferred. These are cartographic layers; the climate source is ERA5, sampled at 0.5°. A dedicated worker renders climate tiles at device density using the previous sampler, palette and Natural Earth clipping. Smooth/Grid affect only display, never numeric readouts, coverage or calculations. Missing native values stay gray. Inspection uses the original climate cell. Crosshair indicates inspection; grabbing appears only during drag. The shared details panel, city/state search, rankings, rules and URLs are preserved. PNG exports keep the same climate sampler and local Natural Earth / state borders, remain independent of screen zoom, and require no external map service. Interactive cartography needs access to tiles.openfreemap.org; no API key is required. MapLibre requires WebGL. USA exports follow the selected contiguous/Alaska/Hawaii preset.

Climate statistics are versioned on Cloudflare and served by the Cloudflare static asset worker `comfy-days-climate-era5`. The Sites `dist/` package contains the interface and default metrics. Custom calculations fetch the same exact statistics from the data worker; no credentials are included in the browser.

Primary custom domain: https://comfy.lfsadigital.com. Climate tile PNG caches are bounded to 64 tiles in the rendering worker. Geographic clipping processes only intersecting rings. Canceled tile requests are dropped; the layer uses revision-specific URLs to avoid stale colors after filters or view changes. Coastline extension indexes are reused. City ranking caches invalidate when climate arrays change. MapLibre handles vector tile loading, label collision and rendering.

LFSA visual system: navy #0A2463, deep navy #061640, gold #F5C518, blue #2DA0E0; Space Grotesk headings and Inter body, bundled as WOFF2. Source: Obsidian/04-LFSA/LFSA-Digital.md. Brand controls and surfaces are separate from the climate data palette; no climate arrays or rules changed in this visual update. PNG exports use the same typography and navy labels.


ERA5 validation uses independent daily reference calculations and checks all seven periods against the unchanged JavaScript engine. Browser checks cover default/custom values, World/Europe/USA parity, wheel/drag/keyboard/pinch, geographic zoom anchoring, street-level labels and roads, US states, search, rankings, responsive widths and six PNG exports. Evidence and import provenance are documented in `docs/ERA5-MIGRATION.md`. External cartography and scientific source data have separate attribution.

Optional sunshine: off by default, with an initial 6 hours/day minimum. Visitors can choose 0–24 hours in 0.5-hour steps. When enabled, subtract 0.5 point per missing hour, with the daily zero floor applied after all penalties. Comfortable days require temperature, rain and sunshine limits on the same date. Mean sunshine/day appears in the shared details panel even while the rule is off. Rankings, URLs and PNGs use the same applied rules.

The sunshine archive was processed remotely on GitHub Actions. Temperature/rain object hashes and all 14 original score/day map hashes remain unchanged. ERA5 direct radiation uses the published Open-Meteo solar method to estimate sunshine, distinct from daylight. The data service uses no-store headers and bounded client memory; daily archives are not saved locally. Current standard ranges use compact presets for sunshine off or 6h, with daily lows on or off. The original archive baseline retains its older sunshine presets. Custom combinations stream daily files and take longer. In the local browser check, a custom 2025 calculation took about 24 seconds; the remote full six-year worker check took about 142 seconds. Other devices and networks can take longer. See `docs/SUNSHINE.md` and the sunrise method's AGPL attribution.

Verified release checks: all 599,893 cell/period results compared with the JavaScript engine; all 955 remote asset hashes, sizes, CORS and no-store headers; 26,304 API reference days (maximum daily sunshine difference 0.185 seconds); 516 browser comparisons; 48 enabled-sunshine ranking checks; 12 PNG exports.

ERA5 migration: see `docs/ERA5-MIGRATION.md` for ingestion, UTC aggregation, sampling and validation. `docs/MIAMI-SOURCE-VALIDATION.md` records the measured coastal-source discrepancy reviewed before the migration. Production publication is recorded in the operations log after verified deployment.

City ranking population thresholds: 1,000, 10,000, 50,000 (default), 250,000, 500,000, 1 million, 5 million, and 10 million residents. These use the GeoNames catalog population, not metropolitan-area estimates. Regions with fewer than 10 eligible cities show fewer results; empty selections show an explicit message.

## City context and monthly charts

Nomads score/cost data and filters were removed pending redistribution permission. Optional city ranking and map marker filters use population plus municipal homicide and a selected crime year. Local rates use FBI Table 8 and Eurostat; UNODC country data was withdrawn pending redistribution permission. Missing local data has no country fallback. See [city homicide coverage and matching](docs/CITY-HOMICIDE.md). Monthly charts use the same ERA5 cell and UTC dates. See [methodology](docs/CITY-CONTEXT-AND-MONTHLY.md) and [design](DESIGN.md).

USA regional budget: optional EPI2026,1adult/nochildren,2025USD including taxes. County-based, not city-specific. Missing stays Unknown. Data adaptations are CC BY-NC-SA4.0; see docs/EPI-BUDGET.md.


## Optional historical air quality

Weather includes an off-by-default, inclusive historical median US AQI limit (100 initially) and an independent period (2025 initially; 2023–2025 also available). Enabling it filters city points and Top 10, hides the continuous climate raster, and retains unverified or insufficient AQI as unknown, using outlined map points. Climate scores, days and arrays stay unchanged; disabling restores the original map/ranking. Checks load progressively with explicit provisional, continue and retry states. See [source, methods and verification](docs/AIR-QUALITY.md).
